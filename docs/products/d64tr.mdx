# D64TR

The D64TR is a dual-sensor EO/IR gimbal camera for MAVLink-enabled autonomous platforms. It combines a 64 MP RGB camera, a FLIR Boson+ 640 × 512 thermal camera, 3-axis stabilization, and on-device edge AI compute.

## Highlights

- MAVLink-ready imaging, capture, zoom, tracking, and status integration.
- 15 TOPS edge AI for object detection and tracking workloads.
- Gigabit Ethernet, 1080p HDMI output, CAN, UART, SBUS, PPM, and USB 3.0.

## Compute Platform

The D64TR uses the Lantronix Open-Q 5165RB SOM based on Qualcomm Dragonwing QRB5165. See the [Lantronix Open-Q 5165RB SOM specification](https://www.lantronix.com/products/open-q-5165rb-som/) for the external component reference.
