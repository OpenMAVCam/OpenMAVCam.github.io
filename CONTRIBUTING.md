# Contributing

Use English for public content. Every Markdown or MDX page needs a `title` front matter field. Keep sidebar IDs ordered, keep D64TR values in `src/data/products/d64tr.ts`, and do not hotlink product images.

Run `npm ci` and `npm run validate` before opening a Pull Request. Create releases as `blog/YYYY-MM-DD-<slug>.md` and use conventional commit messages.
